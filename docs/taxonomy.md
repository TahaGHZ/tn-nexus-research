# Taxonomy

Use these exact values in record frontmatter. To add a value, add it here in the same PR.

## sectors

`water`, `energy`, `agriculture`. A finding may list more than one.

## theme

**Water**
- `groundwater` — aquifer levels, overexploitation, illegal wells
- `surface-water` — dams, reservoirs, siltation, transfers between regions
- `drinking-water` — supply cuts, network losses, access
- `irrigation` — irrigated areas, techniques, efficiency
- `wastewater-reuse` — treatment and reuse
- `desalination`
- `water-quality` — salinity, pollution
- `water-governance` — pricing, allocation, institutions

**Energy**
- `electricity-mix` — generation sources, gas dependence
- `energy-imports` — trade balance, security of supply
- `energy-subsidies`
- `grid` — losses, outages, peak demand
- `renewables` — deployment, barriers
- `buildings-cooling` — air conditioning, heating, insulation
- `industrial-efficiency`
- `transport-energy`

**Agriculture**
- `crop-choices` — water-intensive crops, export orientation
- `soil` — degradation, erosion, desertification, salinisation
- `cereals`, `olives`, `dates-oases`, `livestock-feed`
- `land-structure` — fragmentation, tenure
- `inputs` — fertiliser, pesticide, seed
- `food-loss`
- `drought-climate` — climate impact on yields

**Cross-cutting**
- `nexus` — the problem only exists because two sectors interact
- `legacy-policy` — a past decision whose effects are still felt

## timeframe

`past` (started and largely played out before 2015), `current`, `predicted`.

## geography

`national`, a region (`north-east`, `north-west`, `centre-east`, `centre-west`, `south-east`,
`south-west`), or a governorate name in lowercase (`kairouan`, `gabes`, ...).

## root cause types

`policy`, `technical`, `economic`, `behavioural`, `climatic`, `institutional`.
